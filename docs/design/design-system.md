# Fleetline design system

The implementation references are `supervisor-dashboard.png` and `mobile-field-flows.png` in this directory.

- Canvas: true white with `#f3f6f8` secondary bands.
- Navigation: `#13263a`; primary action: `#167c80`; safety emphasis: `#e86f2d`.
- Typography: system sans, strong sentence-case headings, deliberate control labels.
- Geometry: 6-8 px radii, thin cool-gray borders, almost no shadow, open tables/lists instead of nested card grids.
- Controls: at least 44 px high, visible focus ring, semantic label, icon plus text for status.
- Desktop: 205 px navigation rail, compact top search/status bar, content-first work tables.
- Mobile: single-column field flow, large categorical buttons, full-width primary actions, role-specific bottom navigation.
